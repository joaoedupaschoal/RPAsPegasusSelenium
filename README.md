🐍 RPA Pegasus Selenium – Ambiente de Desenvolvimento

Este repositório contém as automações RPA do Pegasus utilizando:

Python 3.11

Selenium

WebDriver Manager

PyAutoGUI

Faker

Python-Docx

PyInstaller

Este guia ensina como configurar o ambiente corretamente para rodar e editar o projeto.

🚀 Pré-requisitos

Windows 10 ou 11

Python 3.11 instalado
→ ⚠️ Não use Python 3.12 ou 3.13 (problemas com PyInstaller + Faker)

Git instalado

🧱 1. Clonar o repositório

git clone https://github.com/joaoedupaschoal/RPAsPegasusSelenium
cd NOME_DO_REPO


🧪 2. Criar ambiente virtual
python -m venv venv
